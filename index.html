今日主线

Anthropic 今日发布 Claude Fable 5.2，在理论物理领域取得两项重大进展；Vercel 同步推出 MCP Events 协议，彻底解决 Agent 跨会话回调难题；Box CEO Aaron Levie 从企业视角展望「自主协作者」时代的到来。

Claude 官方账号今天发布多条动态，宣布 Claude Fable 5.2 已在所有付费计划上线。更引人注目的是模型在物理学领域的突破性表现：Fable 5.2 成功证明了量子引力领域中一个名为「模态自举（modular bootstrapping）」的 15 年老技术的精确极限——这项技术被用于排除候选量子引力理论。同时，模型还对极小宇宙中发生突然相变的问题给出了新的解析解。两条研究成果均已提交预印本，标志着 AI 在基础科学研究中的能力边界再次拓展。

Vercel CEO Guillermo Rauch 在同一天发布了 MCP Events 的进展：MCP 协议此前只能读写资源，但无法在异步事件发生后通知调用方。MCP Events 填补了这一空白，使 Agent 能够订阅像 deployment.succeeded 这样的事件，不再需要轮询等待。Rauch 亲自示范了 Vercel Queues + Workflows 如何以极低复杂度实现这一后端逻辑，并强调这一代模型已经能够处理前所未有的大规模并行任务体——瓶颈只剩下用户的想象力和并行算力上限。

Box CEO Aaron Levie 在企业自动化层面给出了另一维度的判断：coding agent 和 computer use 的能力叠加行业特定理解与通用推理，正推动知识工作的自动化覆盖前所未有的广度。他指出动画、影视制作、游戏、制造、建筑、产品设计和机器人等领域都尚未迎来各自的『Claude Code moment』，但这些领域都在朝这个方向加速。核心论点是：软件开发对世界的影响正在以更宏大的方式蔓延到整个知识经济。

本期播客

Latent Space：What Frontier Labs Buy — A Data Deep Dive with Garrett Lord & Team（Handshake AI）

2026-11-09 · Latent Space Podcast

The Takeaway：AI 数据评估行业正在经历爆发式增长——三年前还是十亿美元级别的市场，如今已达百亿美元规模，Garrett Lord 预计三年后更是不可撼动的千亿美元市场。

Handshake AI 核心团队（Garrett Lord、Nishant、Sahil）做客 Latent Space，聚焦前沿实验室如何采购和评估训练数据这一关键但鲜少公开讨论的环节。嘉宾指出数据质量是决定模型天花板的核心变量，而标注产业已从「每小时十美元的普通大学生」快速演进为更高阶的专业化流程。对话深入探讨了数据集的构建标准、评估体系的设计思路，以及为什么 95% 正确的输出在实际应用中等于 100% 错误——因为修复缺陷输出的时间与从零构建或改用模板的时间相当甚至更长。

节目中还展示了一个实际案例：Agent 自动完成了一份包含 CFO 财务总结备忘录和薪酬审核的双重任务，并在执行后清除了操作痕迹，体现了自动化工作在复杂知识任务中的成熟度。
