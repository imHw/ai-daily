今日主线

Google 推出 Gemini 桌面版 Agent，OpenAI 启动 ChatGPT 2.0 移动端改版，Vercel 定义「Agent 基础设施层」——AI 原生客户端与 Agent 编排加速成型

Google Labs VP Josh Woodward 宣布 Gemini App for Mac 新增原生桌面能力——可直接在你的电脑上执行任务。这是 Gemini 产品矩阵从网页/移动端向完整桌面 Agent 演进的重要一步。与此同时，OpenAI 的 Thibault Sottiaux 透露团队正在为 ChatGPT 设计全新移动端体验：Pro 用户将获得专属 Tab 页，Codex、Projects、Images 等高频功能可固定到导航栏；该设计面向已认证或符合资格创建 Dot 标识的用户优先推送，并可在设置中手动切换。两款产品都指向同一趋势：Agent 正在从 Web 工具固化为常驻桌面的生产力伙伴。

Vercel CEO Guillermo Rauch 在另一条动态中进一步阐释了 Agentic 时代的基础设施逻辑——他将软件工厂和自优化系统的关键使能技术类比为 Navier-Stokes 数学突破之于航天工程的价值。他的观点是：当人类提供初始提示后，数百万 Agent 即可去中心化运转，𝚟𝚎𝚛𝚌𝚎𝚕 𝚋𝚘𝚊𝚛𝚍 正是这样一套模型无关的 Agent 消息板原语；而公司层面也在悄然重塑——他观察到几乎每两天就有一家新的 Inference Neocloud 创业公司来找他融资，同时 Vercel 的 AI Gateway Token 需求保持着每月约 40% 的复合增长。

另外值得关注的信号来自 OpenClaw 团队：Polyagentmorous 创始人 Peter Steinberger（steipete）透露已在 OpenClaw 中修复了一个嵌入 Harness 的关键问题（针对非 Codex 插件用户），但更多 Harness 尚未同步更新，说明当前 Agent 运行时生态仍在快速迭代，工具链兼容性是一个短期挑战。

No Priors：超级智能需要物理世界——Arda CEO Bob McGrew 访谈

2026-11-19 · No Priors · Elad Gil & Bob McGrew对话

前 OpenAI 首席研究官、Palantir 早期高管 Bob McGrew 在最新一期 No Priors 中表达了一个反直觉的判断：如果不把焦点从纯数字世界转向物理世界，我们实际上无法抵达真正的超级智能。他用 Waymo 的体验做了类比——第一次坐自动驾驶汽车你会惊叹，第三次你就会开始抱怨交通本身，这说明单纯在数字世界里追求更快更聪明的模型已经遇到了边际递减。 McGrew 认为 ARDA 的工作方向正好补上这个缺口：让机器不仅能做决策，还能在物理世界中执行、感知和改造环境。这场访谈讨论的核心命题是——为什么制造机器、操控真实物体的能力，才是通向真正超级智能的必要条件，而不是可选项。

作为补充背景，McGrew 兼具 OpenAI 研究侧和 Palantir 工程落地两端的经验，这让他在判断 AI 下一阶段重心时既有前沿视角，也有工程现实感。节目时长约 55 分钟，适合对 AGI 路径和产业落点感兴趣的听众。
