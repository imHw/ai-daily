英伟达新任董事黄仁勋高调回归，AI 基础设施格局再受关注

今天最炸裂的消息是 NVIDIA CEO 黄仁勋重返英伟达董事会。Sam Altman 在 X 上仅发了一个 "Jensen!"，收获了 8.5 万点赞、3400 次转发和 2000 条回复——这是 OpenAI CEO 的 X 账号至今最高互动量之一。Matt Turck 发文称 "AI Jesus is risen"，Nikunj Kothari 调侃 "Nvidia board took this one personally"。Aditya Agarwal（SPC GP）则从更宏观的角度解读：英伟达经历危机后只会变得更强、更具攻击性。这一事件预示着 AI 算力竞争进入新阶段。

Boris Cherny @bcherny · Claude Engineer @Anthropic

一年前我们发布了 Opus 4.5，第一个能写出我 100% 代码的模型。但 PR 提交能力没能跟上，所以今天正式发布 Claude Ship Beta。我建议先从一个仓库开始，用 Observa Mode 运行 Approvals 建立信任后再逐步放开。Code Review 负责找 bug，PR Steward 处理修复和检查失败，Claude Approvals 按团队策略审批——后两者目前处于 beta 阶段。 原推 →

Amjad Masad @amasad · CEO @Replit

Replit 新研究揭示了 Agent Swarm 的扩展定律：固定两小时窗口内，Opus 5.5 单 Agent 实现 NumPy 3.7 倍加速，而 32 个 Agent 达到 18.9 倍；GPT-6.2 Astra 作为最强单 Agent 却在超过 8 个 Agent 时出现负向扩展。模型自发形成了不同组织结构，去中心化 swarm 比依赖集中协调的扩展效果更好。问题的可并行性是 swarm 表现的最强预测因子，而单个模型的智能程度反而是集体智能的糟糕预测指标。 原推 →

Thibault Sottiaux @thsottiaux · Codex & ChatGPT @OpenAI

如果你好奇 OpenAI 内部那些 obsession 地修补开源软件和基础设施缺陷的人在想什么，值得听一下这段访谈。另一个重要更新：一旦质量提升推送到你账号，你会明显感受到 ChatGPT 回答质量的飞跃。结合我们在简化应用、提速以及合并聊天与工作模式上的所有投资，年底前日常体验会有相当大的改善。Dots 正在快速成为 OpenAI 内部完成任务的主要方式——甚至有团队在用 dots 构建 dots 系统本身。 原推 →

Aaron Levie @levie · CEO @Box

服务型企业一直受制于交付结果的能力——规模化只能靠增加人手，无论需求多大，能招到的人才总是有限的。客户永远希望更快、更便宜、更高质量地完成工作。Agent 彻底改变了这个算式：现在我们可以将产出与时间脱钩。一个工程师可以有几十个工程师的输出，一个设计师可以独立完成整套设计系统。关键是在前端仍需专家确保 agent 交付正确结果。未来我们会看到网络安全、营销、法律、会计、IT 转型等领域大规模采用这种模式。 原推 →

Guillermo Rauch @rauchg · CEO @Vercel

Vercel 正在加倍投入日本市场！另外，我用 Fable 分析了自己所有的编码会话来决定 Opus 还是 Gemini Neon 更好用——它选了 Neon。Google 如此强力回归这件事被广泛且严重低估了。关于 AI 设计的建议：如何用非设计师身份避免 AI 生成的平庸设计感也值得关注。 原推 →

Madhu Guru @realmadhuguru · Sr Director, AI @Meta; Prev: Google (Gemini/Veo/Nano Banana)

数据这个名字严重低估了它在模型开发中真正的分量。不熟悉模型开发的人把数据视为惰性商品——像煤一样买来塞进模型。但实际上优质数据编码了极高的知识价值、品味和专业判断，往往以以前不存在的结构化方式呈现。这使得数据成为跨领域创造越来越强 intelligence 的核心基石之一。数据将在智能产业中继续占据极其核心的地位。 原推 →

Thariq @trq212 · Formerly Claude Code @Anthropic

X 的分成模式是对未来软件公司的极佳启发：保持精简核心团队，给帮助用户增长、改进和销售的创作者付费。这不是新的商业模式，但在这个 AI 代理崛起的时代尤其有意义。顺便一提，有人分享了一个绝妙的 Hitchhiker's Guide 引用——电影中显示电脑算了 500,000,000 页 Lean 才得出答案 42，却被剪掉了。 原推 →

Garry Tan @garrytan · President & CEO @Y Combinator

初创公司可以在循环中自我 Prompt 的一个技巧：问自己"我们是否在走向死亡？"如果你问了，可能会发现杀死你的那个东西并避开它。这不是新的想法，但在 AI agent 可以帮助持续监控健康指标的当下，这个思路有了新的执行方式。 原推 →
