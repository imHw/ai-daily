今日主线

OpenAI Codex & ChatGPT 产品负责人 Thibault Sottiaux 一条「It's Friday」推文以 5778 赞、1692 评论引爆 AI 圈；与此同时，多位建造者围绕 Agent 实用化、MCP 内嵌_creator 工具、以及评测驱动开发的必要性密集发声，行业情绪从狂热转向冷静审视。

Thibault Sottiaux（@thsottiaux）在 X 上发了一条简短的「It's Friday」配图推文，收获了 5778 赞、110 转、1692 条评论——这几乎是他当天互动最高的内容，甚至超过了他之前关于形式化验证的专业讨论。在同一天，他还分享了一条「用单个 prompt 能做到的事太酷了」的技术展示（492 赞），以及转发一条求助「带我走出地下室」的内容（1776 赞）。综合来看，这位 OpenAI 产品负责人近期在高密度输出技术观点的同时，也以轻松一面触达了更广泛的受众。

Thariq（@trq212，前 Claude Code @Anthropic）连续三条高质量推文引发共鸣：其一吐槽「太多人在建 Agent，太少人在用软件改善虾塘水质」（2269 赞）；其二观察到 Instagram Edits、Roblox Studio 等创作者工具开始内置 MCP，让 Agent 协作与人工接力无缝衔接（1130 赞）；其三发布了一张进展图配文「感觉真的要成了」（1327 赞），暗示 Agent 生态正在从概念走向成熟。

YC CEO Garry Tan（@garrytan）强调「评测驱动的 Agent 技能开发循环必不可少」，并亲自演示移除了 Cursor 中的 /investigate 技能因为 Opus 5.5 已做得更好（217 赞）。Guillermo Rauch（@rauchg）则提出「生成式 UI + 对话 Agent」将成为主流人机交互范式，展示了通过 @aisdk 和 json-render 直接从 LLM 到 Slack/Teams UI 的技术路径（1147 赞）。这些声音共同指向一个判断：Agent 竞争壁垒正在从功能堆砌转向评测优化与工程打磨。

本期播客

Latent Space Ep：控制生物学——Fabian Theis 谈逆向生成模型与自主实验室

2026-11-06 · Latent Space Podcast

The Takeaway：Helmholtz Munich 的 Fabian Theis 介绍了一套名为 Lab Compass 的逆向生成模型系统——给定目标细胞状态，反向推导需要执行的实验步骤，标志着 AI 从「观察+预测」迈向「主动引导实验」的新阶段。

嘉宾 Fabian Theis 是计算生物学领域的标志性人物，其团队持续产出 Scanpy、Anndata 及 scVerse 等开源工具，被全球组学研究者日常使用。本集深入讨论了 AI for Science 的核心范式转移：从构建人类细胞图谱（映射），到训练世界模型做预测，再到如今的逆向生成——告诉科学家「该做什么实验才能达到目标状态」。

Fabian 表示终极愿景是将强化学习（RL）嵌入整个实验闭环：模型预测→指导实验→获得数据→更新模型，实现真正的持续学习。目前论文往往止步于某个模型和概念图，尚未形成完整的迭代循环，但「我们正在慢慢接近那个目标。」
