Serval 创始人 Jake Stauch 在接受 No Priors 播客时详细阐述了企业 Agent 落地的核心矛盾：个人 Agent（如 Dot、Muse）在消费场景运行良好，但在大型企业里权限极度受限——Agent 甚至读不了你的邮件。Serval 的方案是通过 IT 团队的服务账号权限，配合确定性审批流程和审计追踪，让 Agent 能在受控环境中执行高权限操作，本质上是一个带审批流的自动化平台。

本期播客

No Priors #170：直面企业服务 Agent 的安全困境 · Jake Stauch（Serval 联合创始人兼 CEO）

2026-10-29 · No Priors · 约 38 分钟

The Takeaway：企业级 Agent 的核心矛盾不是能力不足，而是权限与安全的根本冲突——你想要的 Agent 越自主越好，但企业在合规和审计面前绝不妥协。Serval 的选择是：不做魔法般的个人助手，而是做一个带完整审批流和审计追踪的企业自动化平台。

Jake Stauch 曾在 Verkada 面向 IT 团队销售物理安全产品，发现 ServiceNow 是 IT 部门最头疼的存在——他们想构建，但没有工程部门，只有配置和审批的繁琐流程。Serval 的思路是绕过传统 ITSM 的限制：通过服务账号获得管理员级别权限，让 Agent 能完成真正有用的自动化，但每一步操作都经过确定性的审批工作流，并且全部记录在案。本质上，Serval 底层就是一个票务系统。

Stauch 强调，相比 Dot 或 Muse 那种"魔法般"的个人 Agent 体验，Serval 的方案更繁琐，但这正是大企业——尤其是受监管行业——能接受的前提。公司成立 18 个月，已融资超 1.25 亿美元，Sequoia 领投，估值达 10 亿美元。产品迭代速度极快，工程师直接面对客户， decentralized 的产品决策机制让他们能随时推翻过去的承诺重新来。
