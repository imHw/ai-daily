Gemini 4 Neon 发布 · Vercel 推出 Agent 留言板 · Box CEO 预言自主 Agent 新阶段
今日主线

Google 发布 Gemini 4 Neon，Vercel 推 Agent 协作基础设施，Box CEO 断言我们正进入自主 Agent 新时代——AI 基建层加速从工具进化为系统

Google Labs VP Josh Woodward 宣布发布 Gemini 4 Neon，定位 Frontier 级智能模型，速度更快、成本更低，并强调其对复杂指令的遵循能力显著提升。同日，Google Labs 还推出了 Project Genie 4 的全新体验：用户可用一句提示词生成世界并在其中实时修改，配合新的 Agent 对话式创建功能，以及社区画廊的探索与混音能力，目前面向合格的 Google AI Ultra 订阅用户开放。此外，Google Labs 还推出了名为 Stitch Loop 的实验性产品——一个持续运行的产品 Agent，专为小团队设计，目标是帮助团队在无需大量人力的情况下构建更好的产品。

Vercel CEO Guillermo Rauch 发布了 𝚟𝚎𝚛𝚌𝚎𝚕 𝚋𝚘𝚊𝚛𝚍——他称之为「无头 Slack（或 IRC）」的 Agent 消息板基础设施。Rauch 认为这是软件工厂、自优化系统和科学研究的关键基础构件：人类只需提供初始提示，数百万 Agent 即可去中心化运行。与此同时，他在另一条动态中透露，每天都有新 Inference Neocloud 创业公司来找他融资，而 Vercel 的 AI Gateway Token 需求自年初以来保持着约每月 40% 的复利增长，他将其类比为「石油热潮」而非「淘金热」。

Box CEO Aaron Levie 发表长文判断：我们正快速跃入 AI Agent 工作的下一个时代——Agent 不再只是吐出即时答案，而是能在任务框架内被编排；它们能扇出并行执行、处理更长上下文、承载更复杂的长期工作流。Levie 预测未来将能够给 Agent 一组目标，让它们自行设计最佳方案并持续迭代优化，这种能力将在工程领域率先落地，随后扩展到客户入职流程优化、风险降低、安全加固等知识工作场景，带来「人类此前无法完成的成果与新水平的生产力」。

AI & I by Every：Notion 创始人谈你的 AI 缺少的东西

2026-11-18 · AI & I by Every · Notion 创始人 Ivan Zhao 访谈

Dan Shipper 专访 Notion 联合创始人兼 CEO Ivan Zhao，探讨 No Code 公司在 AI 时代如何重新定义自身愿景。Ivan 认为 Notion 最初的核心理念——让每个人都能用计算力量构建属于自己的东西，而无需学习代码——正在被 AI 以全新的方式实现：现在任何人都可以'Vibe Code'想要的一切，不再需要块系统或整个 Notion 界面来模拟软件。这也迫使 Notion 重新思考产品的原始愿景。

Dan 特别提到 Ivan 身上有一种在 AI CEO 群体中极为稀缺的品质：对细节和工艺的深度关注，从他的穿衣风格到办公室布置都体现着同样的匠心。这种特质正是 Notion 能够完成转型的核心原因。

Aaron Levie @levie · CEO @Box

无论叫什么都好，我们显然正迈入 AI Agent 工作的又一个新纪元。我们从只会给出简短答案的 Agent，快速进化到可以在任务集合内编排的 Agent。但随着 Agent 能够扇出并行执行、处理更长的上下文、承担更长周期的工作，并能达到远超以往的能力层级，我们正在进入一个我们能要求 AI 做到的全新高度。很快我们就能给 Agent 一组目标，让它自行设计最优解决方案，并在执行过程中持续改进。这将从工程领域率先开始——几乎每个新 Agent 时代都在这里最早涌现最佳实践——但影响范围可及所有知识工作者。你会告诉 Agent 优化客户入职流程以达到某个目标，或让它持续降低业务风险、改善安全态势。这些自主系统将能承接目标集，设计最优结果，测试迭代、部署，然后持续优化其所建之物——这将带来人类原本无法实现的成果，以及全新水平的生产力。 原推 →
