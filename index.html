Training Data：OpenAI 的 Noam Brown 谈游戏理论为何没有通向通用智能

Training Data · Noam Brown（OpenAI）· 2026年11月24日 · No Limit 扑克决赛现场

Noam Brown 在 No Limit 扑克决赛现场接受 Training Data 访谈，复盘从 2012 年读博研究扑克 bot，到 2019 年团队主攻最难的自然语言博弈《外交》，再到 2022 年加入 OpenAI 负责通用推理（o1）的完整路径。他坦言：游戏理论的核心假设是所有玩家理性，但现实中人不理性，Diplomacy bot 因此频繁失败；真正有效的路径不是编码复仇或公平感，而是用海量人类数据训练模型去模仿人的行为，甚至学会建模人类的非理性。他说：「2022 年那对我是一次信仰危机时刻，我意识到游戏理论并不是通向通用智能的路径。」

Aaron Levie @levie · CEO @Box

编程是观察大量知识工作未来的窗口。第一步是从手动完成大部分研究、打字和价值创造，转向协调 agent 完成的工作；下一步是当协调本身也变得多余或拖慢 agent 时，把目标交给 agent 去优化。这看起来像会卡在编程上，实际上很大比例的知识工作最终都会收敛到这种形态。真正的障碍是大量工作不可验证，人类会在环中扮演比编程时代更重要的角色，但可交出去的部分会越来越大。 原推 →
