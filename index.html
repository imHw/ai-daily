今日主线

Claude Code 联合创始人 Cat Wu 离职，OpenAI 明确 AI 红线，Box CEO 发布生产力翻倍测算：两年内从 50% 跃升至 10 倍。

Claude Code 联合创始人 Cat Wu 11 月 3 日发文告别 Anthropic。她回顾两年前还是内部工具时的 Claude Code：她花数十小时引导模型构建 RL 环境，却一行代码未写；首发时用户手动批准每个权限请求，主要用来回答问题写测试。如今默认已转为自动批准，Claude 负责大型重构和产品搭建。「帮助将 Claude Code 打造成定义行业的标杆产品，是一生难忘的旅程。」推文获 9,400+ 赞、260 转发、830 条评论，反响热烈。

OpenAI CEO Sam Altman 11 月 4 日发表长篇声明，明确反对「将人类降格为执行 AI 认为合理的奖励机制的角色」。他指出：人们应始终掌控未来，不应把未来的决定权让渡给超级智能——这一要求最终应约束 AI 的发展边界。推文获赞 10,100+，引发广泛讨论。

Box CEO Aaron Levie 在同日发出深度分析：AI 生产力增益的上限正快速突破。两年前，即便在最对齐的领域（如编程），顶级用户相比普通用户最多提升 30%-50%；如今，随着模型能完成更长任务、harness 支持 agentic 工作流、数据集覆盖更多领域、多 agent 协作系统更成熟，上限已跃升至 5-10 倍，且随 RSI（递归自我改进）加速只会越拉越大。「我们正在经历一个时代奇点。」

Unsupervised Learning Ep 96：Nebius CTO 谈在 AWS 醒来之前加速 hyperscaler 竞争

2026-11-02 · Redpoint AI

The Takeaway：Nebius 的诞生本身就是对云巨头盲区的一次精准狙击——当 AWS、GCP、Azure 还在为既有 workload 的基础设施纠结时，Nebius 用俄罗斯技术人才+黄仁勋人脉，直接为 AI 训练时代定制算力基建。

本期对话深入 Nebius 的起源故事（与 Yandex 的分道扬镳）、内部运作方式、与 NVIDIA 的合作关系，以及下一代芯片上线的实况。嘉宾还分享了对 Disaggregated Inference 等新技术的看法。核心洞察：超大规模云厂商并非不想抢这个市场，而是改变已按传统 workload 建设的大规模基础设施成本太高，这个窗口期因此存在。

对于 AI 基础设施赛道的竞争格局，CTO 给出清晰判断——这不是单纯的算力买卖，而是「在 hyperscaler 还没反应过来之前，用更聚焦的架构抢跑」，值得所有关注 AI 基础设施的人细听。
