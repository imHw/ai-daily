Roadster 惊艳亮相引爆 AI 圈，Box CEO 断言：Agent 蜂群时代 Token 消耗将暴增百倍

特斯拉新一代 Roadster 发布，马斯克设计惊艳全场。OpenAI CEO Sam Altman 第一时间发文称赞："新 Roadster 看起来太棒了，@elonmusk 干得好。"这条推文收获超过 5.5 万赞，成为今天 AI 圈传播最广的一条。Vercel CEO Guillermo Rauch 更是直接动手，用高精度物理引擎重新构建了 Roadster 的可交互模拟——保留了大量真实车辆细节，让网友能在浏览器里体验这辆超跑。

Box CEO Aaron Levie 则在另一条推文里提出了一个更宏大的判断：AI 正跨过某个临界点——自主 Agent 执行复杂任务的能力已超过多数人类工程师，配合并行化的 Agent "蜂群"，模型迭代速度将远超以往任何时期。他认为，从对话式助手到后台自主 Agent 的范式转换，将使 Token 消耗达到当前水平的 100 到 1000 倍。

与此同时，Replit CEO Amjad Masad 分享了一则有趣的观察：数学家们正在经历 AI 冲击下的"哀悼五阶段"——否认、愤怒、讨价还价、抑郁、接受——而且压缩在极短时间内完成。他感慨："我们正处于抑郁末期，即将进入接受期。"

OpenAI 总裁 Greg Brockman：AGI 必须让人类握紧方向盘

No Priors Podcast × Greg Brockman · 2026-10-15 发布

OpenAI 总裁兼联合创始人 Greg Brockman 做客 No Priors 播客，深入讨论了 AGI 安全、网络安全支出激增，以及 AI 如何推动药物研发等领域的新突破。他重申 OpenAI 的核心立场：AGI 必须让人类牢牢掌握方向盘，AI 应该放大人类的能动性，而非取代人类的决策权。

Brockman 提出了一个反直觉的判断：网络安全支出应该远超软件支出。他认为人们尚未充分认识到，AI 时代网络安全的"物理法则"正在发生根本性变化——攻击门槛大幅降低，防御方必须投入指数级资源才能维持平衡。这一观点直指当前企业安全预算的结构性问题。

在药物研发方面，Brockman 透露 OpenAI 内部已在推进相关合作，认为 AI 生成新知识的能力正在从数学证明扩展到生物学和化学领域，有望彻底改变新药发现的效率曲线。
