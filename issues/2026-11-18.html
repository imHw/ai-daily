前 Anthropic 工程师 Thariq 爆推文：软件工厂是过渡态，真正的挑战是构建人机协作工作空间；Box CEO Levie 称每员工 Token 消费曲线仍有天花板；Stanford 推出 AI 原生工程课程引爆关注

Thariq（@trq212，前 Anthropic Claude Code 团队成员）发了一条爆款推：「软件工厂只是临时问题——模型终将学会为你构建它们。真正有意思的问题是：如何建立一个让人和 Agent 能协作的工作空间？」该推获得 4841 赞、200 转发、374 条评论，是目前 follow-builders feed 本周热度最高的内容之一。这句话精准捕捉了当前 AI 基建赛道的认知拐点：当 Agent 开始自主写代码、跑评测、迭代产品，下一个瓶颈不再是算力，而是人机协作的界面设计。

Box CEO Aaron Levie 在同一天发出长篇分析：每员工 Token 消费曲线「目前仍看不到天花板」。他观察到今夏以来的模型发布持续突破 SOTA，编码能力从一年前的「基本不可用」跃升到现在「终于开始好用」，随之而来的是工具使用、Computer Use 等新形态的爆发，让 Agent 可以进入金融、生命科学、网络安全等此前无法触及的知识工作领域。「一旦你能写出能编码、能用电脑、能调用任意工具的 Agent，就能把它们投入到更广泛的知识工作中。」他总结道。

Latent Space 播客本期邀请到 Stanford 教授 Mihail Eric，深度解析该校正在病毒式传播的 AI 原生软件工程课程如何教学——涵盖从 prompt 工程到 agent 工作流的完整方法论，同时他也是 Monaco 的 AI 负责人。

Latent Space：[One Million AI Engineer Special] Stanford 如何教 AI 原生工程——Mihail Eric 对谈

2026-11-08 · Latent Space · Mihail Eric（Stanford 讲师 / Monaco AI Head）

本期为庆祝 AIU Code YouTube 频道突破一百万订阅而特别制作。嘉宾 Mihail Eric 不仅是斯坦福热门课程「Modern Software Developer」的主讲人——这门课正因系统讲授 AI 原生开发最佳实践而在社区病毒式传播——同时还担任 Monaco 的 AI 负责人，兼具学术界与工业界的双重视角。

课程内容涵盖从基础 prompt 技巧到复杂 agent 工作流的设计，重点讲述如何让开发者在日常工程中有效利用 LLM，而非仅仅把它当作问答工具。Eric 结合自己在 Monaco 推动 AI 落地的实战经验，分享了团队在实际项目中遇到的坑和解决方案。

每员工 Token 消费的图表目前没有看到任何天花板。越接近 AI 核心，越能感受到我们才刚刚站在曲线的前端。今夏以来的模型发布不断刷新 SOTA，编码能力尤其明显——一年前几乎不可用，现在终于开始变得真正可用。编码一旦成熟，就打开了工具调用和 Computer Use，进而让 Agent 能够进入金融、生命科学、网络安全等大量知识工作领域。再叠加 Agent Swarm 和后台常驻 Agent，Token 消耗只会继续指数级增长。 原推 →

Guillermo Rauch @rauchg · CEO @Vercel
