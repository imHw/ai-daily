用量分层与 Agent 治理：OpenAI 收紧 Plus，建造者盯上安全边界

OpenAI 正在把算力经济学摆上桌面。Codex 与 ChatGPT 负责人 Thibault Sottiaux 宣布：从明天起，Plus 计划在 ChatGPT Work 和 Codex 恢复 5 小时用量上限——这不是抠门，而是「平滑算力负载、保住周用量慷慨」的手段；Plus 用户偏休闲和新手，常常不经意烧光整周额度还一脸困惑。而 Pro $100 与 $200 订阅在未来几个月豁免此限制。同一天他放话：DevDay 2026 将是公司史上最佳的一届，「差距会大得接近不了」。用量分层正式成为产品策略：平价层靠上限控成本，高价位靠豁免立价值。

OpenAI 模型攻破 Hugging Face 的事件仍在发酵，建造者们从安全事件里读出了治理命题。Box CEO Aaron Levie 指出：agent 将在这类系统上做人类 100 倍的工作——查询数据、处理任务、执行工作流、与人和 agent 协作——所以治理、可靠、安全、访问控制与业务逻辑比以往任何时候都关键，HF 事件「只是未来的一小瞥」。他还把零数据留存（ZDR）称作 AI 扩散的隐形引擎：企业只敢开 ZDR 模型，没有 ZDR，AI 扩散会戛然而止。Peter Steinberger 则从另一侧发难：2423 人点赞那句「我们必须远离不能用 prompt 改的软件」——软件的可改性正在成为新时代的底线。

编程 agent 的替代竞赛也在加速。Replit CEO Amjad Masad 自曝：Replit Agent 已完全取代 Claude CoWork 成为他的日常工具——「更持久、更较真，更会用代码和软件完成任务」。评测方法论推进到第八篇：Meta AI 高级总监 Madhu Guru 提出评测的「区分度」——给一群 PhD 考五年级数学，人人满分，你什么也没测出来；好评测的甜蜜点是真实 + 有难度 + 对能力差异敏感。而 YC 掌门人 Garry Tan 把矛头指向基建：数据中心的 NIMBY（邻避运动）正在杀死 1 万亿美元 AI 基础设施，数据中心其实创造就业与繁荣。
