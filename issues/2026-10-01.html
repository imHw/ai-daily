OpenAI Dev Day 释放三大信号：Dots 24/7 智能体、Ultrafast 极速模型、Sol 6.1 降价 80%

Sam Altman 在 OpenAI Dev Day 上正式发布 Dots——一种新型 AI 使用方式，能够 24/7 为用户工作，「帮你把时间和注意力收回工作本身」。配套推出 Ultrafast 模式，号称「快到我再也不想回去」，以及 Sol 6.1 模型，价格仅为 Astra 的 1/5，缓存读取享 95% 折扣。

Thibault Sottiaux 透露，Dots 将在数日内上线数百万实例，用户将用它们处理各种任务。他在实测后发现，经过 2-3 天调教后，Dots 学习速度极快，能独立承担「相当雄心勃勃的任务」，并预告未来将开放创建整个 Dots 团队的能力。

GitHub SDK 周下载量突破 3000 万，Rauch 用 ffames + Opus 制作了一支 GPU 渲染的视频展示这一里程碑，「用 Rust 编写、GPU 渲染」，展现 AI 辅助开发的高效率闭环。

Claude in Chrome 正式版上线

Claude Blog · 2026-08-26

Claude in Chrome 现已在全部付费订阅中正式可用。Claude 可在浏览器中自主执行操作，无需逐项确认——每次操作前会经安全分类器验证，确保行为安全且符合用户意图。

该功能已支持读取页面、输入文本、点击链接、页面导航和表单填写，并复用用户现有登录状态。针对 prompt injection 攻击，Anthropic 持续改进模型训练与探测机制，增强对隐藏指令的防御能力。
