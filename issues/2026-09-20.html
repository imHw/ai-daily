Claude Code 迎来 AGENTS.md 支持 · 30,000 个 Agent 驱动 Anthropic 研发 · OpenAI 下周将公布重大更新

Claude Code 今日在 2.1.277 版本中正式加入 AGENTS.md 支持——若项目中没有 CLAUDE.md，Claude 将自动读取同级 AGENTS.md 作为指令源。这一改动回应了超过 4,300 名工程师的长期诉求，意味着团队在同一代码库中同时使用 Claude Code、Codex、Cursor 等多个 AI 编程助手时，只需维护一份共享的 AGENTS.md 文件，无需再为每个工具维护重复的配置。用户可在 /config 中切换该行为。

Anthropic 今日披露了一组令人瞩目的内部数据：截至 8 月，Claude 已主导公司 26% 的模型研发工作——这一比例在同年 2 月还是 0。目前 Anthropic 内部同时运行约 30,000 个 Claude Agent，超过 90% 的研发工作有 Claude 作为协作者或主导者参与，所有操作均经过实时监控，8 月份超过 10 亿次 Agent 决策中有约 0.002%（即约 20,000 次）被拦截。Anthropic 强调当前仍属人类监督下的 AL4 级别自主，尚未声称递归自我改进。

OpenAI 首席技术官 Thibault Sottiaux 透露，他与 CEO Sam Altman 及 Romain Huet 正在准备下周的公开 Keynote，内容「多到令人难以置信」，将在短时间内陆续揭晓。业界普遍猜测可能涉及新一代 GPT 模型、Astra 多模型编排框架的更多细节，或更自主的 Agent 能力。

No Priors: 扩散模型为何将赢得 AI 推理

Stefano Ermon | Stanford 教授 / Inception 联合创始人兼 CEO

本期 No Priors 播客邀请到 Stefano Ermon——斯坦福教授、扩散模型领域奠基人之一、现任 Inception CEO。他从 2014 年进入生成模型研究说起，分享了扩散技术从早期无人问津到成为 AI 核心基础设施的演变历程。

Ermon 的核心论点是：速度、效率与可扩展性将成为未来几年 AI 推理的竞争关键，而扩散架构在这一方向上具有独特优势。Inception 正以此挑战 OpenAI、Anthropic 等头部实验室在推理领域的主导地位。他同时讨论了模型成本、延迟优化以及如何在不依赖超大计算资源的前提下实现高质量生成。
