今日主线

Aaron Levie发长推：agent时代的工作方式正在被重写；Gemini钱包功能上线，UI SDK展示两句话生成应用

Box CEO Aaron Levie 连发长推，核心观点是：AI 模型在编程、工具使用、数学等认知任务上会持续变强，而 agent 恰好擅长这些——因此 agent 领域的进步速度将超过其他知识工作范畴。他进一步指出一个反直觉的判断：不是只有少数工作会被自动化，而是越来越多的工作会被「编码化」来适应 agent 的能力，最终呈现为动画视频、游戏、3D 模型甚至 Cyber/生命科学/金融等领域的应用。这意味着软件价值不再取决于模型知道多少知识，而在于它能否高效地驱动工具、产生可执行的代码输出。

Google 方面，Josh Woodward（@GoogleLabs @GeminiApp）宣布 Google Wallet 深度集成已面向美国 Gemini App 用户开放。用户可以即时生成本月消费图表、追踪订阅涨价、基于去年实际支出规划假期预算——这对消费者财务透明度的切入角度非常具体，也是 Gemini 从通用助手走向场景化个人助理的关键一步。

Vercel CEO Guillermo Rauch 分享了自己用 uisdk + Gemini Argon 在两句话提示词内搭出一个完整 Web Component 音乐控制台的体验，agent 自动复用了窗口缩放、拖拽、菜单悬停切换、typeahead、漫游焦点、10 段 EQ 滑块等 14 个组件行为，全程无框架依赖，仅靠纯 Web Components 完成，并配 Suno 生成的 BGM。同时他提到用 smart model 规划 + fast model 子 agent 协作的架构模式，把项目拆成一行指令委托给子 agent 执行，这种分层代理范式正成为生产级 Agent 的标准做法。

Unsupervised Learning Ep 97：Jeb Creator 谈决策建模、基准疲劳，以及大模型实验室为何错过了什么

2026-11-05 · Redpoint AI · Jeb（TypeSave CEO）

这期节目的核心争论围绕 Anthropic IPO 前的估值校准与 AI 能力预期展开。Jeb 认为当前市场对 Claude 及其背后的技术路线存在一些系统性误读，尤其是关于'让 AI 治愈癌症'这类宏大叙事，他直言不讳地将其比作玛丽·安托瓦内特的'让他们吃蛋糕'——听起来美好但脱离现实约束。

Jeb 还回顾了 JEV（他的开源基准测试项目）发布一个月后的反思：早期结果不如预期，但这让他更清晰地意识到真正需要解决的问题类型，以及如何在评测设计层面减少噪声。他强调 benchmark 疲劳正在蔓延，行业需要回归到那些真正反映实际工作负载的数字，而非姿态性的排名竞赛。
