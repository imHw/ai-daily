感恩节周末，Altman 复盘「千禧年大奖题」背后的信念文化

今天是美国感恩节周末，不少建造者进入了「感恩模式」，但仍有一条值得展开的暗线：Sam Altman 特意点名「Ven 是最早相信 OpenAI 当时已有的模型就能解千禧年大奖题的人之一」。这件事要追溯到 9 月 8 日：OpenAI 宣布约 1 万个 agent 用 88 小时给出 Navier-Stokes 方程（千禧年七大难题之一、百万美元奖金池）奇异性证明，并用 Lean 完成形式化验证，过程中消耗约 1300 亿输出 token，还牵扯出与 NYU 教授及 Anthropic 研究者「并发工作」的争议。Altman 这条感恩节推文，实际是在数学震撼之后重述团队的信念文化——「聪明 + 把信心放对位置、敢在别人认为不可能的地方继续推」是稀缺品质。

产品侧三条：Google Gemini 4 家族（Argon/Carbon/Hydrogen/Neon，近两个月内相继 GA）已可在 Replit 使用，Replit CEO Amjad 亲自点赞；OpenAI 针对 GPT-6.2 计费 bug 承诺的 banked reset 补偿正式上线，Codex 团队 Thibault 一条推文确认；Codex 团队的 Nan Yu 则说，语音聊天、发图、给指令换回一个网站「现在全是 chat」——ChatGPT 的单一会话界面正在把多种模态收编。服务行业侧，Box CEO Aaron Levie 认为 agent 给交付能力带来 10 倍乘数，广告、IT 转型、管理咨询、金融等服务公司正处于重构窗口。

本期播客

Latent Space：Thariq Shihipar（OpenAI）谈「软件工厂」之后是「软件文艺复兴」

Latent Space · Thariq Shihipar（OpenAI，前 Anthropic Claude Code 核心团队）· 2026年11月26日 · 录于 AI Engineer (AIE) Code Summit 闭幕

Thariq（刚宣布加入 OpenAI，传闻任务之一是「重新发明 Codex」）在 AIE 做闭幕演讲「Revolution vs Renaissance」：AI 既是工业革命也是文艺复兴——2026 是「软件工厂」之年，工业化带来更便宜的软件，下一阶段是用这份便宜做个人化、高品质作品的文艺复兴。他认为大量「AI slop」的根源是人在构建过程中根本没亲自使用和测试，所以他做了 /slash human「human folder」：spec 本身就是可运行代码，高注释密度、禁止单字符变量名，让你边用边迭代。他正在做一款《文明》式卡牌游戏 Frontier Lab，让 Claude 跑了数千局模拟后发现「经济胜利」永远是必胜策略、而模型很不擅长修平衡——他把它当成一个 eval：模型是否理解跨越数千回合的系统？

模型观上他不是「永久底层」信徒：$200 订阅还没触顶，真正卡他的是「和模型协作的方式」；他正在试 decision models（TypeSafe 称之为 System 1 models），认为现有 harness 远没有用好它们。对 RSI，他的判断是 AI 研究会变成「知识工作」——做决策、分配算力资源、说服人；最重要的形式是模型优化自己的预训练/后训练，但「今天的模型还做不到自己发明出投机解码这种东西」。花絮：主持人调侃他是「失业的职业魔兽世界玩家」——不少 RL/预训练研究员出身于 WoW 公会，游戏是「成就感的假肢」。
