今日主线

Richard Socher 融 6.5 亿美元打造递归自我改进引擎 · 个人 Agent 的终局产品形态浮现 · 开放模型 Token 用量再创新高

AI 学术界最高引研究者之一 Richard Socher 此前创办的 Recursive 今日成为焦点——公司已筹集 6.5 亿美元，专门致力于「递归自我改进」（RSI），即让 AI 自主产出更优 AI。Socher 在 MAD Podcast 中阐述了他的核心论题：科学进步之所以放缓，是因为人类已无法跨学科整合爆炸式增长的知识碎片，而 AI 恰好可以像微积分之于物理那样，为生物学等复杂系统重新编织知识。他的新书《The Eureka Machine》即将出版，被视为 RSI 革命科学的蓝图。Socher 强调，凡可模拟或可验证的领域，AI 必将达到超人水平；而创意的门槛也已被实证跨越——其联创 Jeff Kuhn 多次目睹 AI 生成的构想数月后被人类研究者独立发表。

Box CEO Aaron Levie 发表了对个人 Agent 产品形态的深层思考：个人 Agent 是「建造 Agent 想用的东西」这一理念的终极体现——用户将任务全权委托，Agent 必须能端到端完成。这要求 Agent 能操作你的工具（MCP/CLI）、在你的网站上导航、完成交易等。竞争的关键不再是用户注意力，而是 Agent 的注意力——你能否成为 Agent 优先调用的那个服务。与此同时，OpenAI 产品团队的 Nan Yu 反馈，Muse 和 Instinct 目前均声称无法拨打电话，暗示个人 Agent 的端到端能力仍在滚动部署中。

Vercel CEO Guillermo Rauch 的观察延续了开放模型崛起的主线：AI 最令人兴奋之处在于所有人都开始热衷于建造而非消费，这是对世界不可估量的好事。此前 Vercel AI Gateway 的开放模型 Token 占比已达 78.4%，远超闭源模型的 21.6%，Moonshot AI 和 DeepSeek 的合计支出已超过 OpenAI 本身。这一结构性趋势仍在加速。

MAD Podcast: 递归自我改进如何重启科学进步

Richard Socher | Recursive 创始人兼 CEO / AI 最高引研究者之一 / 新书《The Eureka Machine》

本期 MAD Podcast 邀请到 Richard Socher——AI 领域被引次数最高的研究者之一、Salesforce 首席科学家、现 Recursive 创始人。他刚为公司筹集 6.5 亿美元，致力于实现递归自我改进（RSI）。对话从他的新书《The Eureka Machine》开篇论题出发：科学进步为何放缓——不是因为缺乏研究者或资金，而是知识碎片化到任何单一天才都无法跨学科整合的程度。

Socher 的核心类比是：AI 对生物学的意义，如同微积分对物理学的意义——它能将我们已理解的无数微观碎片重新编织成宏观图景。在可模拟或可验证的领域，AI 必然达到超人水平；而创意的门槛已被实证跨越——他观察到 AI 生成的构想数月后被人类独立发表。他同时强调，现有技术加上更多数据和算力，已足以治愈大量疾病、应对衰老、改进聚变反应堆、创造新材料，这些都在可及范围内。
