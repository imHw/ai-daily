Claude Marketplace 正式上线可发现工具与 Agent · ChatGPT Voice 全生态体验刷屏 4000 赞 · Vercel 发布 Drives 为 Agent 配外接存储

Claude 官方正式发布 Marketplace，4249 赞成为今日最高互动推文。用户可以在 Marketplace 上发现工具、Agent 和专家合作伙伴——添加 Slack、Notion 等连接器，购买 Cursor、CrowdStrike 等公司的 Agent 产品，或接入 Accenture、Deloitte 等服务伙伴规模化部署。Boris Cherny 同日分享 Claude Code 和桌面端近期大幅加速的技术内幕，3292 赞，揭示了让应用「快到可感知」的工程技巧。

OpenAI 方面，Thibault Sottiaux 发推分享 ChatGPT Voice 的深度使用体验——打电话聊工作、查邮件、写代码、管日历，全生态插件打通含第三方，4009 赞刷屏。他随后预告下周二 DevDay，称这是 OpenAI 最有野心的 sprint，Astra 让新功能在极短时间内成为可能，3159 赞。Josh Woodward 则宣布更多应用接入 Gemini。

Vercel CEO Guillermo Rauch 拆解成功 Agent 的三组件架构——Brain（模型+harness）、Hands（工具+浏览器+计算机）、Files（记忆+技能+仓库），并发布 Drives：为 Sandbox 的 agent 计算机提供可挂载的「外接磁盘」，支持离线读写记忆和技能文件，1453 赞。Rauch 强调组件解耦不仅优化成本，更从根本上提升安全性和可审计性。
