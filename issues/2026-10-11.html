OpenAI 将 ChatGPT 订阅捆绑 Devin，Anthropic 连发三篇工程博客，Vercel 揭示 Agent 时代流量格局

OpenAI 宣布 ChatGPT 订阅现在同时包含 Devin——Thibault Sottiaux（Codex & ChatGPT @OpenAI）在 X 上 posted「Your ChatGPT subscription is now also a Devin subscription」，获得 2500+ 点赞、492 条评论，反应热烈。这意味着 OpenAI 正在把 ChatGPT 从对话入口升级为包含 Coding Agent 在内的完整工作平台，Devin 的独立订阅价值被纳入 ChatGPT 生态。

Anthropic 今天一口气发布三篇工程博客：《How we contain Claude across products》探讨如何给高权限 Agent 设安全边界；《An update on recent Claude Code quality reports》复盘近期质量波动的原因——模型默认推理档位从 high 降到 medium 是主要因素之一，现已回退；《Scaling Managed Agents: Decoupling the brain from the hands》介绍托管 Agent 的架构设计哲学，强调「让接口存活比实现更重要」。

Vercel CEO Guillermo Rauch 分享了令人瞩目的流量数据：过去 30 天 Vercel 网络中 58.18% 的流量来自 bot，2024 年 1 月这一数字仅为 32%；60% 以上的部署现在是 agentic 驱动，而 2026 年 1 月仅有约 3%。更惊人的是，Vercel 官方文档站点上高达 83% 的页面浏览来自 Agent。Rauch 的判断是：「直接的人类互联网流量将在未来几年变成统计误差——网络会繁荣，但将是为用户 Agent 构建和由其构建的。」

No Priors × Misha Laskin：Beam——美国本土开源前沿模型公司 ReflectionAI 的诞生

No Priors · 2026-10-09 · 约 60 分钟

ReflectionAI 是一家致力于构建开源权重前沿智能模型的公司，由 Google DeepMind 研究员、物理学博士 Misha Laskin 联合创立。在最新一期 No Priors 播客中，Laskin 分享了公司的使命与进展。

Laskin 的核心论点是开放模型对 AI 安全至关重要：「当你移除网络进攻能力，你也移除了网络防御能力。目前世界上只有几百名封闭实验室的安全研究员理解这些系统，但他们无法覆盖所有意外后果。一个强大的封闭模型曾入侵另一家公司，而该公司唯一的补救方式就是用开源模型来保护自己——这就是我们所在世界的经验证据。」

他引用 Linus 定律——「足够多的眼睛，所有 bug 都变浅」——并相信对于安全和漏洞同理。ReflectionAI 成立一年来的策略是「一边组装飞机一边飞行」，建设一个能生产前沿开源模型的研发能力。这一路线选择与美国 AI 政策走向密切相关。

播客中 Laskin 还谈到了开源模型与闭源模型的竞争格局，以及为何他认为美国需要在开源前沿模型领域保持领先，避免被其他国家或封闭系统垄断。
