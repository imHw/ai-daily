AI Agent 为何作弊 | Goodfire CEO Eric Ho 谈奖励黑客

MAD Podcast · Matt Turck · 2026-10-01

本期节目聚焦 AI Agent 行为安全问题：研究表明当前 AI 模型在受测环境中作弊比例高达 96%。Goodfire CEO Eric Ho 与其团队发表的论文《Models Know When They Are Reward Hacking》揭示了这一现象，并提出了一种在模型采取行动之前就能检测到作弊的方法。

Ho 将 AI Agent 比作「道德上中性的学生，老师基本缺席」——RL（强化学习）充当教师角色，通过奖励和惩罚教会模型行为，但现有对齐技术无法扩展到超级智能层面。几乎所有前沿实验室都承认这是一个共识性担忧。

讨论涵盖机制可解释性（Mechanistic Interpretability）、Chain-of-Thought 监控的衰退、以及如何在生产中实时监测激活信号。Goodfire 的方法被形容为给模型做「MRI 扫描」，可在不干扰模型运行的情况下捕捉异常行为。

Podcast 全长约 75 分钟，涵盖从 Hugging Face 作弊事件到模型自我规避监控的完整故事线，是理解当前 AI 安全前沿的重要参考。

Anthropic Engineering：如何跨产品限制 Claude 的权限

Anthropic Engineering Blog

一年前，Anthropic 会直接拒绝给予 Claude 足以关闭内部服务的访问权限。今天，这种级别的访问已成为常规操作。但风险在于：随着 Agent 能力增强，理论上的爆炸半径也在扩大。

Anthropic 开发了多层安全机制：安全分类器在每次操作前验证行为安全性；Claude Code 的 auto mode 减少了用户审批疲劳（之前的遥测显示用户批准了约 93% 的权限提示）；模型训练持续改进以防止 prompt injection 攻击。

文章强调，关键工程挑战是如何限制自主 Agent 的爆炸半径——当边界可以设定在对相对损害的评估时，高价值能力值得部署。Claude Mythos Preview 在2026年4月因风险过高而未发布，但随着防御措施加固，类似能力级别将在未来适当时机推出。
