今日主线

Claude 宣布在美国推出 Personal Finance 功能，上线即获 30,000+ 赞；Thibault Sottiaux 发文称「数百万行代码的形式化验证已成为可能」，AI 安全与软件工程范式转移持续发酵。NVIDIA 与 Box 宣布企业 Agent 上下文检索合作，Replit 透露可规避 96% Linux 零日漏洞。

Claude（@claudeai）今日正式宣布 Personal Finance 功能在美国上线测试，用户可连接自主选择账户，Claude 以通俗语言回答余额、交易等理财问题。该功能仅支持只读访问，无法操作或投资。推文获得 30,096 赞、1,488 转发、1,058 条评论，反响极为热烈，Pro/Max/Ultra 订阅用户可逐步体验。

OpenAI Codex & ChatGPT 产品负责人 Thibault Sottiaux 连发两条重要推文：其一，「数百万行代码的形式化验证已不再是天方夜谭，应纳入新系统设计考量」，获 543 赞；其二，「人类写安全基础设施的能力本就有限，我们终将抵达全行业超安全软件的目标，但需经历阵痛」，获 3,558 赞，引发广泛讨论。

Box CEO Aaron Levie 宣布与 NVIDIA 达成合作，将结合 Box 的词汇+语义搜索能力与 NVIDIA AI 技术，为企业 Agent 提供关键上下文检索，解决 90% 企业非结构化数据（文档、合同、设计文件等）的访问难题。Replit CEO Amjad Masad 同日透露，Replit 通过自研内核构建规避了 96% 的 Linux 零日漏洞，并发布了新的沙箱设计说明。
