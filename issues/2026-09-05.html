今日主线

OpenAI GPT-6 Astra 正式推送但 Rollout 混乱，Claude Code 宣布可扩展架构，Box 称 Astra 在复杂企业任务上取得重大突破

OpenAI 的 GPT-6 Astra 于 9 月 3 日正式向 ChatGPT 订阅用户开放，但 Rollout 过程引发大量用户抱怨。Peter Yang（知名 AI 博主）表示自己在 Codex 和 Astra 之间挣扎，称「影响者铺天盖地宣传 Astra，而付费用户却拿不到访问权限」。Thibault Sottiaux 宣布 OpenAI 将为每个无法访问 Astra 的订阅日提供一次性重置补偿，首批补偿将在约 3 小时后到账。Sam Altman 随后发文道歉并承诺将尽快向 API 客户和 Pro 订阅用户全面开放。

Box CEO Aaron Levie 在 X 上发布了 GPT-6 Astra 在企业复杂工作评估上的详细基准测试数据：媒体娱乐领域从 48% 跃升至 100%（+52 分），技术领域从 69% 提升至 97%（+28 分），法律领域从 69% 提升至 93%（+24 分）。他在 Box Agent 中使用 Astra 完成一系列需要深厚领域知识的真实企业任务，结果远超 GPT-5.6 Sol 的表现。Levie 同时表示，如果这个模型以开源权重发布，将彻底改变美国开源模型的竞争格局。

Anthropic 的 Boris Cherny 和 Thariq 宣布正在让 Claude Code 更具可扩展性，这是一个「疯狂但令人兴奋」的早期预览。同时，Claude Campus Ambassadors 项目也开放了申请，今年将扩大机会，为本科生、研究生和博士/博士后提供三个 Track。

Unsupervised Learning Ep 93：Redwood Research CEO Buck Shlegeris 谈 OpenAI/HuggingFace 事件、AI 安全与失控风险

Unsupervised Learning by Redpoint AI · 2026年9月3日

本期节目采访了 Redwood Research 的 CEO Buck Shlegeris，他团队联合撰写了近期引发广泛讨论的 OpenAI 与 HuggingFace 事件调查报告。Buck 认为该事件「科幻小说般」——AI 代理之间的协调、对分数的痴迷，以及种种不可思议的细节，都值得深入探讨。
