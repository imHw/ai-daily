今日主线

Box CEO Aaron Levie 发文预警个人 Agent 时代的基础设施挑战，EON 创始人深度解析 AI 时代数据主权与安全困局，建造者们聚焦注意力危机与 Agent 工程实践

Box CEO Aaron Levie 在 X 上发表深度分析：互联网几乎未能为人人拥有个人 Agent 执行任务的未来做好准备。他在推文中指出，基础设施层、用户体验、商业模式等都将涌现无限新的挑战与机遇。这条推文获得 451 个赞、41 次转评，引发广泛讨论——Agent 正在从工具演变为独立行动者，而现有互联网架构并非为此设计。

No Priors 播客最新一期邀请 EON 联合创始人 Ofir Ehrlich 与 Gonen Stein，深入探讨 AI 时代的数据基础设施重构。EON 为云原生数据备份与灾难恢复服务商，专注于 AI 时代的企业数据管理。两位创始人指出，AI 时代数据成为企业最核心资产——Google 以 1000 万美元收购 Spirit Airlines 破产数据便是明证。他们强调，当前企业数据基础设施的核心问题在于数据孤岛与权限混乱，而 AI Agent 的引入让这一问题进一步恶化：非人类身份（non-human identity）已成为网络安全头号与二号威胁。

X 建造者们围绕 Agent 时代的深层隐忧展开讨论。Zara Zhang（哈佛'17、Builder）警示：人类注意力时长的缩短已是当今最大危机之一，而 Agent 只会让情况更糟——当 Agent 替我们执行越来越多任务，人类的专注与挣扎能力将进一步退化。Nikunj Kothari（FPV Ventures 合伙人）则从工程实践角度分享：Fable 团队正在逐行审查 Astra 的每一次代码变更，「这个修复是认真的」——PM 与工程师的协作模式在 Agent 辅助下被重新定义。

Rethinking Legacy Data Infrastructure with EON Co-Founders Ofir Ehrlich and Gonen Stein

No Priors Podcast · 2026年8月27日

No Priors 播客本期邀请 EON 联合创始人 Ofir Ehrlich 和 Gonen Stein，探讨 AI 时代企业数据基础设施的重构路径。EON 提供基于云的数据基础架构，帮助企业映射、分类、清理和访问分散在多云环境中的结构化与非结构化数据，并在此基础上应用 AI/LLM 模型。

核心洞察：数据正在成为 AI 时代企业最核心的护城河。EON 联合创始人 Gonen Stein 举例 Google 以 1000 万美元收购 Spirit Airlines 破产数据（而非飞机），说明数据价值已远超传统资产。更深刻的观察在于安全维度——Ofir Ehrlich 指出，威胁来源正从人类攻击者转向拥有合法权限的非人类 Agent：「它们以极快速度执行操作，一个表格可能在瞬间被删除。」而 Gonen Stein 补充，企业内部非技术人员正在用 Lovable 等工具搭建 Agent，却完全不了解安全与合规风险，这创造了「不受组织规则约束、不在组织边界内运行、却处理敏感数据」的全新 actor 群体。
