Cursor 决裂余波未平：Codex 预告新里程碑，MCP 生态爆发，行业重心转向「评估与标准」

OpenAI 与 Cursor 决裂的消息余波仍在发酵。Codex 与 ChatGPT 负责人 Thibault Sottiaux 在断供公告之外再度放出信号：盯着仪表盘看，明天可能就要迎来一个值得庆祝的历史新里程碑，并呼吁开发者「Hold on to your Codex」。就在生态站队白热化之时，Replit CEO Amjad Masad 把目光投向另一个被低估的方向——「增长型 Agent」（Growth Agent），认为这是尚未被充分开发的巨大潜力。

Vercel CEO Guillermo Rauch 则用数据印证了 Agent 协议的爆发：MCP 正在爆炸式增长，实现 MCP 服务器的 npm 包 mcp-handler 下载量飙升，增长远不止 Vercel MCP 一家。他同时提醒：市面上「简单」做 Agent 的方式很多，但能让你真正拥有整套智能技术栈——运行时、模型选择、技能、工具、连接——并以 Git 仓库形式沉淀为自有资产的并不多。

当模型能力不再是唯一瓶颈，建造者们开始把注意力转向评估标准。Every 宣布迎来首位 Head of EVALS，Dan Shipper 断言「AI 里没有坏主意，只有弱模型」；VC 们也在收紧自己的判断框架——Matt Turck 晒出热门轮次的尽调现场，Nikunj 直言最好的 pitch 根本不需要出现「AI」这个词。
