Box CEO 论 Agent 时代的商业摩擦消融 · Thariq 警惕生产力反噬 · Rauch 原生浏览器实验

Box CEO Aaron Levie 发出 Agent 时代商业重构的核心判断：当 Agent 开始为人类做最优决策，传统「切换成本」将被瓦解——医疗、旅行、本地服务等曾因摩擦而过重的市场将被重新激活；但也有大量依赖用户惰性的行业会面临激烈竞争直至均衡。他预言：一个由 Agent 深度中介的未来，「不可能与今天完全相同」。

Anthropic 的 Thariq 发出冷静警告：我们最大的风险不是 Agent 太笨，而是人类「吃掉 Agent 带来的生产力增益，只是因为变得更懒了」。4322 赞引发广泛共鸣——生产力工具如果不能转化为真正的产出跃升，只是温水煮青蛙。

Vercel CEO Guillermo Rauch 公布个人项目：把 Mini 网页浏览器用 Rust + Swift 重写，放弃 Electron + Bun，获得 Liquid Glass 原生体验、更快启动和更精细的焦点/输入控制。他判断「原生是未来」——桌面端和云端都将加速 nativify。

Box's Aaron Levie: On Reinventing Yourself in the AI Age and Enterprise Diffusion

Training Data · 主播 · 嘉宾 Aaron Levie（Box 创始人兼 CEO）· 2026-09-15

Box 是面向企业的内容管理与协作平台，正在借助 AI 获得全新生命力。Levie 与主播探讨三个主题：AI 如何重塑企业软件生态、创始人如何在 AI 浪潮中 reinvent 自己、以及 Agent 经济学对传统商业模型的深层冲击。

核心论点：Agent 将瓦解「摩擦护城河」。Levie 指出，许多行业（医疗、旅行、本地服务）的高价格和高壁垒来自「切换成本」——用户懒得换、难换。Agent 让「找最优解」变得零摩擦，这些市场的竞争将骤然加剧，直到新旧势力达到新均衡；而依赖用户惰性的细分市场则面临颠覆性重构。

对从业者的启示：Levie 强调创始人必须主动 reinvent，而非等市场倒逼。他反复提示：当 Agent 开始替用户做决策，「为摩擦定价」的商业逻辑将彻底失效——企业需要重新思考 value prop 是交付给人类还是交付给 Agent。
