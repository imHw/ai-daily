IDE 代理战争升级：OpenAI 宣布断供 Cursor，Anthropic 深度复盘 Claude Code 退化之谜

AI 编程赛道迎来标志性决裂。OpenAI（Codex 与 ChatGPT 负责人 Thibault Sottiaux）正式宣布将在 11 月 12 日终止与 Cursor 的合作，停止向其直接提供模型访问权限，核心原因直指「信任问题」。Thibault 同时预告 Codex 即将迎来历史新里程碑。此举瞬间引发生态重构：Anthropic Claude Code 团队成员 Thariq 迅速表态赞赏 Cursor 并承诺全力合作；Replit CEO Amjad Masad 则宣布在 Replit 上免费开放 OpenAI 模型，并愿意出资赞助企业从 Cursor 迁移。编程入口之争彻底从暗战变为明火执仗的生态站队。

Anthropic Engineering 连发两篇硬核工程复盘。其一详尽拆解了此前用户反馈「Claude 变笨变健忘」的真相：排查确认 API 未受影响，而是客户端三处改动叠加导致的连锁反应——将默认思考强度降至 medium（已回滚为 xhigh/high）、清理闲置会话思考缓存的 bug 导致后续每次交互误删推理历史、以及系统提示词加入「工具间输出≤25词」的控字指令损伤了智力。其二则系统阐述了「托管 Agent 架构」（Managed Agents），核心原则是将「大脑」（Harness 循环）与「双手」（Sandbox 沙箱）彻底解耦，将沙箱视作随时可销毁重建的牲畜，同时将凭证隔离在沙箱外部杜绝注入攻击。

建造者们对行业演化速度达成罕见共识。Box CEO Aaron Levie 与 Meta AI 高级总监 Madhu Guru 分别提出「AI 信念 6 个月半衰期」与「产品打法 3 个月半衰期」——传统团队沉迷于一套 Playbook 吃五年，而前沿实验室每隔数月就得推翻旧认知。Vercel CEO Guillermo Rauch 则预言 Web 正分化为两大极端：一端是服务于人类愉悦的高端视觉体验，另一端则是纯粹面向 Agent 的 Markdown 与 MCP 机器协议，中间地带将被实时生成的 JIT 界面彻底吞噬。

No Priors｜重构遗留数据基建：数据是 AI 时代唯一不可替代的重资产

No Priors · 2026年8月27日

No Priors 邀请云原生数据与容灾平台 Eon 联合创始人 Ofir Ehrlich 和 Gonen Stein 深入探讨 AI 时代的底层数据架构。Eon 创始人指出：在当前环境下，模型架构和算力基础设施正日趋同质化，企业的切换成本几乎为零；而企业私有数据是唯一具备不可替代价值的核心资产。最具代表性的例子是 Google 在精神航空（Spirit Airlines）破产清算中，以 1000 万美元专门收购其全量历史运营与客户数据用于模型训练，而非购买其实体飞机资产。

Eon 正在构建跨多云环境的统一数据底座，让冷备份与归档数据不再只是沉睡的保险箱，而是能够被 LLM 和 Agent 随时检索与分析的活跃资产。创始人同时提醒：随着非技术员工也能在企业内部随意组装 Agent，大量不受现有合规框架约束的「影子 Agent」正在私自调用与处理敏感数据，这让跨云的数据治理与访问控制成为当下最紧迫的安全防线。

Claude Code 性能退化深度复盘：三个工程妥协的连锁反应与托管 Agent 架构

Anthropic Engineering · 2026年8月

Anthropic 首次公开复盘 Claude Code 体验退化的根本原因。排查确认 API 层完全正常，问题源于客户端三处优化改动的叠加：3 月为缓解长耗时将默认思考强度降至 medium（已于 4 月 7 日全面恢复最高档）；3 月 26 日为优化闲置会话缓存引入 bug，导致后续每次交互误将旧思考历史全部剔除，使模型表现出「健忘与重复」；4 月 16 日为控制输出字数加入「工具调用间≤25词」的系统提示词，评测显示智力下降 3%（已于 4 月 20 日撤回）。团队已重置所有订阅者用量额度，并引入更严格的模型隔离评测门禁。

在另一篇工程长文《Scaling Managed Agents: Decoupling the brain from the hands》中，Anthropic 提出了托管 Agent 的解耦范式：将 Agent 拆分为 Session（只增事件流）、Harness（状态机大脑）与 Sandbox（计算沙箱）。沙箱被作为随时可故障替换的牲畜（Cattle）管理，认证 Token 与凭证被严格隔离在沙箱外部，杜绝提示词注入劫持；同时将 Session 事件流置于上下文窗口之外，使 TTFT（首 Token 延迟）在 P50 下降 60%、P95 下降超 90%。
