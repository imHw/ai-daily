英伟达风波未平，AI 基础设施的地缘政治暗流浮出水面

黄仁勋重返英伟达董事会的消息在周五引爆整个科技圈后，本周的讨论仍在持续发酵。Sam Altman 那条仅一个单词的 "Jensen!" 推文已收获超过 8.5 万点赞——这是 OpenAI CEO X 账号历史最高互动之一。但真正值得关注的不是事件本身，而是它暴露出的深层结构性问题：Nikunj Kothari（SPC GP）指出，这一风波说明 AI 算力供应链已经被地缘政治深度缠绕，任何单点故障都可能引发全球连锁反应。Amjad Masad 在 X 上发文称，即便美国能做出最好的前沿模型，仍可能在 AI 竞赛中落败——因为政府层面的算力管制正在重塑全球竞争格局。Matt Turck 则以更务实的角度指出，Anthropic IPO 定价低于 Nvidia 峰值股价，这是一家成立了近六年的公司，市场给予 AI 基础设施的估值溢价远超应用层。

产品层面，本周有两件值得关注的事：Anthropic 正式发布 Claude Ship Beta——面向 Team 和 Enterprise 用户的自动 PR 提交流程，Boris Cherny 亲自站台解释产品诞生缘由；OpenAI 方面，Thibault Sottiaux 宣布 ChatGPT Business 用户将在年底前享受免费快速模式和账户重置功能，同时 Dots 系统正在成为公司内部任务执行的主要方式，尽管 Peter Yang 试用反馈仍显 buggy。Replit 同步发布了 Agent Swarm 扩展定律研究，揭示多 Agent 协作的非线性性能特征。

本期播客

Unsupervised Learning Ep 98：中国专家解读黄仁勋回归

Jordan Schneider · China Talk · 2026年11月24日

本期紧急节目邀请了 Jordan Schneider（China Talk 主持人），深入分析黄仁勋被董事会短暂解除职务又迅速复职背后的政治博弈。Jordan 将此事比作拿破仑从厄尔巴岛返回的「百日王朝」——局势远未稳定。他认为民主党必然会在国会对此事大做文章，而更根本的问题在于：AI 在美国公众中并非热门议题，这使得相关争议更容易失控。Jordan 强调，董事会之所以敢做出这样的决定，背后一定得到了特朗普方面的某种承诺——可能是一揽子和解与赦免方案。这一事件的真正意义不在于英伟达内部治理，而在于它揭示了 AI 基础设施已成为美国国家战略的核心战场。

Boris Cherny @bcherny · Claude Engineer @Anthropic

一年前我们发布 Opus 4.5，第一个能写出我 100% 代码的模型，但 PR 提交流程没能跟上。今天正式推出 Claude Ship Beta。建议从一个仓库开始，用 Observa Mode 运行 Approvals 建立信任后再逐步放开权限。Code Review 负责找 bug，PR Steward 处理修复和检查失败，Claude Approvals 按团队策略审批——后两者目前处于 beta 阶段。MCP 服务器现在也可以自带 skills，Claude Code 开箱即用。 原推 →

Amjad Masad @amasad · CEO @Replit

美国即使能造出最好的前沿模型，仍可能在全球 AI 竞赛中落败——这就是黄仁勋回归为何影响深远。Token 需求的增长是阶梯式的：当找到新方法让单个用户调用更多算力时，需求会突然跃升，这和电力不同。Replit 新研究还发现，固定两小时窗口内，Opus 5.5 单 Agent 实现 NumPy 有 3.7 倍加速，32 个 Agent 达到 18.9 倍；但 GPT-6.2 Astra 作为最强单 Agent，超过 8 个 Agent 时出现负向扩展——模型的个体智能反而是集体智能的糟糕预测指标。 原推 →

Thibault Sottiaux @thsottiaux · Codex & ChatGPT @OpenAI

Aaron Levie @levie · CEO @Box

服务型企业一直受制于交付结果的能力——规模化只能靠增加人手，无论需求多大，能招到的人才总是有限的。Agent 彻底改变了这个算式：现在产出可以与时间脱钩。一个工程师可以有几十个工程师的输出，一个设计师可以独立完成整套设计系统。关键是在前端仍需专家确保 agent 交付正确结果。未来我们会看到网络安全、营销、法律、会计、IT 转型等领域大规模采用这种模式。 原推 →
