Sonnet 5.5 正式发布：效率跃升背后的 Agent 范式转移 · OpenAI Dev Day 明日启幕

Claude Sonnet 5.5 今日正式上线。Anthropic 团队在 Claude Code 中的实测数据显示：相比 Sonnet 5，任务完成量提升约 30%，速度提高 24 秒，token 消耗减少 6K；Boris Cherny 进一步指出整体 bug 修复速度更快、token 用量减少 30%。这意味着同样的产出可以用更少的成本完成——Agent 的每次循环变得更便宜、更可靠。

Box CEO Aaron Levie 分享了企业知识库场景下的实测数据：Sonnet 5.5 在 Box Agent 上比 Sonnet 5 整体提升 4 分，且以 12% 更少的 token 量在 2.4 倍更快的速度下交付结果；金融、法律、生命科学、公共部门四大垂直领域分别实现 +18pp、+7pp、+8pp、+7pp 的提升。当 enterprise content 都变得这么好用时，Agent 的中层应用护城河正在被重写。

OpenAI Dev Day 明日（9月30日）开幕——这是 Dan Shipper 观察到的「OpenAI 历史上发布最多的一次」。Sama 预热称「我们发现了新东西」并获 8097 赞。Thibault Sottiaux 同步公布 Pro $200 订阅调整：取消 5h 硬性限制，每月实际 API 消费折半，且未来会继续降价让利；更重磅的是「更多不消耗 usage 的新功能」将在明天揭晓。
