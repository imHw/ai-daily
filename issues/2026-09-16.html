Claude Code Mods 上线、Vercel 挖角 Google Cloud Run 创始人、OpenAI 本周或将发布重磅更新

Anthropic 今日宣布 Claude Code Mods 正式落地，社区已开始涌现创意作品——包括用 Claude 编写的俄罗斯方块。同时，Google 扩展其 Gemini Power User 内测项目：两个月前启动的早期体验计划已测试超过 20 个功能，新一批用户获准接入 Daily Brief 与 Personal Intelligence 相关功能。Vercel 则宣布聘用 Google Cloud Run 的创建者 Steren，负责 Fluid 系列计算产品（Functions、Containers、Sandbox、Builds），标志着 serverless 之后的下一代计算范式竞争升温。

OpenAI 方面，Codex 团队成员 Thibault Sottiaux 放话「本周将交付 DevDay 2025 级别的更新」，引发社区热议——他同时发起投票询问用户希望从 Codex 中移除哪些功能，获得超过 8000 点赞和近 9000 条评论。Anthropic 工程师团队连续发布多篇技术博客，探讨如何在产品中安全管控 Claude 的智能体权限、解决近期质量回退问题、以及通过 Managed Agents 架构实现大脑与手脚的解耦。

AI & I by Every：专业写作者如何用 AI 写作

AI & I 播客 · 采访 Katie Parrott（Every 资深撰稿人）与 Natalia Quintero

The Takeaway：AI 写作的最佳实践不是让机器替你做，而是把 AI 当作思维伙伴——前提是你已经经历过一段深刻的个人低谷，找到属于自己的对话方式。

Katie Parrott 在 Every 的资深撰稿人，两年前的今天她刚经历裁员与心理健康危机，转而用 ChatGPT 当职业教练，开启了从 AI 怀疑论者到 AI 写作者的转变。本期节目中，Natalia Quintero 与她深入探讨了这一旅程。

Katie 分享了她开发 'Compound Writing' 插件的灵感来源——借鉴 Kieran Klassen 的 Compound Engineering 方法论。她强调：「写作不是让 AI 替你写，而是让 AI 帮你理清思路，再用自己的声音表达出来。」
