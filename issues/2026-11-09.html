Karpathy 3分钟 Claude Code 一枪打爆网红站 · Thibault Sottiaux 探路 ChatGPT Pro 50 · Garry Tan：AI时代最紧迫的政治问题是「丰饶还是黑暗」
今日主线

Andrej Karpathy 用 Claude Code 三分钟复刻「TristanTube」引爆关注，Thibault Sottiaux 询问 ChatGPT Pro 50 档位设想过热；与此同时，Garry Tan 发出「丰饶 vs 黑暗」的世纪之问，Aaron Levie 断言 AI 生产力已跃升一到两个数量级——建造者们正在用行动定义 AI 落地节奏。

前 Tesla/YouTube AI 负责人 Andrej Karpathy（@karpathy）本周发布了一条极简工具链实践：将 Tristan 整理的 4.7 万条 nerdy YouTube 频道列表一键封装为带 TV 模式的浏览界面（TristanTube），全程仅用 Claude Code 一行指令完成，获 6445 赞、515 转、475 评论。这条推文迅速成为本周高互动内容之一，也印证了「一个 prompt 的威力」这一 Agent 实用化叙事的持续升温。

OpenAI Codex & ChatGPT 产品负责人 Thibault Sottiaux（@thsottiaux）在同一天密集输出三条动态：先是发起「ChatGPT Pro 50 该不该有？」的社区投票（1369 赞），接着详细拆解 Pro 各档位的用量对比——Pro 100 = Plus 的 10X、Pro 200 = 20X、Pro 500 = 50X 并含 ultrafast 访问权限——引发用户对定价梯度的广泛讨论（2756 赞），最后转发了一张名为「Cyber」的配图（1601 赞）。这组内容释放出 OpenAI 仍在试探价格天花板与产品线边界的信号。

YC CEO Garry Tan（@garrytan）发表了一篇风格激进的判断：「我们本可以拥有丰饶——这将是未来十年最具决定性的政治问题——是让人类通过超级智能在科学、医学和工程上继续进步，还是选择走向黑暗？」这条推文获得 314 赞。同期，Box CEO Aaron Levie（@levie）从企业视角佐证了 AI 的加速效应：「我们看到越来越多例子证明，配合正确的 harness、深厚的领域理解和多 Agent 协作模式，代码产出已经比 AI 前时代提升一到两个数量级。」他同时指出，AI Agent 的理论推理延迟不敏感，使得长周期 Agent 将成为常态。

No Priors × Vlad Tenev（Robinhood CEO）：Tokenization、Agentic Trading 与 Making Math God（Harmonic）

2026-11-05 · No Priors Podcast

The Takeaway：Robinhood 已从零佣金股票应用蜕变为覆盖预测市场、私有公司股权、代币化资产的全球金融 conglomerate，其核心叙事是「ownership」（所有权）——让每个人都能在经济中持有资产。CEO Vlad Tenev 认为，当前 AI 太中心化（大厂+秘密模型+大型数据中心），而 Robinhood 通过 Harmonic 项目试图做一件相反的事：打造一种分布式的数学超级智能。

Vlad 透露，目前已有超过 15 万用户开通了 Robinhood 上的 Agentic Trading 账户——由 AI Agent 自动执行交易策略的产品已获得明确的产品市场契合（PMF）。对于预测市场，他称其为「新闻的进化形态」，通过赔率可以看到未来可能发生什么。

Vlad 出身东欧（生于苏联解体前夕），移民美国后在 Terence Tao 指导下学习数学、做过 HFT。他在访谈中反复强调「所有权是社会稳定的基础」，并引用自己的经历说明为什么 Robinhood 要做「使命型组织」而非传统金融公司。
