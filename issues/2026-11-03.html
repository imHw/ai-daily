Karpathy 周末两小时做出 HackerTube · Levie：Agent 正在重写工作定义 · Rauch 呼吁「拥有你自己的智能」
今日主线

Karpathy 用 Claude 过滤 4300 万评论打造 HackerTube；Levie 提出 Agent 时代的工作范式转移；Rauch 呼吁掌握自己的智能栈。

Andrej Karpathy 周末两小时搞定了 HackerTube：用 Claude 过滤了 20 年 HN 积累的 4300 万条 YouTube 评论，筛选出 6454 个持续被推荐的优质视频。不需要登录，缩略图来自视频中段帧而非 A/B 测试优化过的封面。整个过程中他只做了三件事：申请 Google Cloud API key、租一台 VPS、买域名——其余全部交给 Claude Code 执行。这个案例再次印证了一个趋势：过去需要数周甚至数月的独立项目，现在可以通过 few-shot 示例加 LLM 协作在几小时内交付。

Box CEO Aaron Levie 发布了关于 Agent 时代工作本质的深度思考：我们正在从「AI 帮人类更高效地做工作」转向「人类帮 Agent 完成工作」。这意味着大多数岗位的核心职能将从个体贡献者转变为「Agent 团队的管理者」。在信息密集型领域（编程、网络安全、法律、生物医疗、工程）尤其明显。Levie 强调，率先发现这一变化并据此重构运营的组织将获得复利式回报——因为杠杆不再与工作时间成正比，Agent 可以并行执行任意规模的任务。

Vercel CEO Guillermo Rauch 发布了一条关于「Own your intelligence」的立场声明：凡是试图垄断智能 access 的人，最终都想把智能以更高价格卖回给你。他呼吁本地模型必须持续普及，关键是拥抱开源，掌握自己的 harness、数据、连接和运行时。与此同时，他分享了实测 Gemini 完成两个高复杂度项目的正面体验。

Unsupervised Learning #95：Modal CEO 谈推理的未来、GPU 市场的混乱与 Sandbox 的起源

2026-10-28 · Unsupervised Learning · Redpoint AI

The Takeaway：GPU 市场远非高效市场——它更像是一个「开放的毒品市场」，人们在大堂里交换号码来寻找芯片。Compute 的结构特性决定了它不会短期内变成标准化可交易的资产。

Modal CEO Eric 回顾了过去三年构建 AI 计算基础设施的历程。他从两个层面分析了 GPU 市场现状：一方面资源确实存在，另一方面结构性低效将持续很久——compute 不是 fungible contract，无法在交易所标准化买卖，这决定了基础设施层的价值将继续存在。

他提到 Sandbox 的起源故事：最初是为了让 Agent 安全运行不可信代码而设计的隔离环境，后来演变为更广泛的推理基础设施。这一演进反映了 AI 应用从封闭测试走向规模化部署的必然需求。
