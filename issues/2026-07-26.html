DoorDash 创始人：机器人公司的前世今生与 Agentic Commerce 的爆发

DoorDash 联合创始人 Andy Fang 和 Stanley Tang 在 No Priors 播客中透露，DoorDash 过去八年实际上是一家机器人公司。他们早在 2018 年就押注自主驾驶和机器人技术，当时这一方向远不如今天明显。如今 DoorDash 拥有超过 900 万 Dashers 和每年 30 亿次配送量，正在 Phoenix 等地全面部署 L4 级自动驾驶机器人。

在 Agentic Commerce 方面，DoorDash 的 Ask DoorDash 功能展现出惊人数据：50% 使用该功能的用户订单来自从未尝试过的新餐厅，grocery 品类购物车规模扩大 40%。DoorDash 正在从对话式搜索走向真正的 Agent-first 体验，甚至通过 DoorDash CLI 让 AI Agent 直接参与配送场景——比如监控 pantry 货架并自动补货。

Building an Autonomous Delivery Experience with DoorDash Co-Founders Andy Fang and Stanley Tang

No Priors · 2026年7月23日

DoorDash 联合创始人 Stanley Tang 回顾了从 2018 年一个"skunkworks"实验到今日 Phoenix 数百台自动驾驶机器人的历程。他们发现，真正的挑战不是自主驾驶本身，而是围绕它构建的整个生态系统——基础设施、商户集成、首次和最后 100 英尺的取送问题。DoorDash 最终决定自研，因为市面上没有现成方案适合他们的配送场景。

Andy Fang 则分享了 Agentic Commerce 的洞察。他指出，Google 搜索查询链接正在变长，说明人们越来越习惯用自然语言与 AI 交互。DoorDash 正在将这种对话体验扩展到语音模式（支持 Opus 和 Sonnet 模型）、多语言，并通过 CLI 让 Agent 直接参与商业流程。他们收购 Metis 以注入 AI-native 思维，AI 支出在 6 月份同比增长了 20 倍，但通过基准测试和优化正在控制成本。

Claude Code now supports artifacts

Claude Blog · 2026年6月18日

Claude Code 现在支持 artifacts——将工作进展捕获为可实时更新的可视化页面。一次 Claude Code 会话可以涵盖从调查事故到重构服务再到分析数月数据的各种任务，artifacts 将这些工作转化为任何人都能打开和探索的网页，包括 PR walkthrough、系统解释器、仪表盘和发布清单。

每个发布都是同一链接下的新版本，带版本历史。典型使用场景包括：安全审计发现关联到具体代码行、SRE 事故页面随调查自动更新、工程经理展示本周实际合并的内容。目前以 beta 形式面向 Claude Team 和 Enterprise 组织开放。
