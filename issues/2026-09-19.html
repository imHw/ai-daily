Claude Code 正式推送 Projects · Google CC 进军家庭场景 · 亚秒部署再进一步

Anthropic 今日宣布 Claude Code 正式推出 Projects 功能——每个项目拥有独立 Agent，统一管理记忆并调度子 Agent 执行任务。用户可以设定 Agent 主动执行、定时运行等策略。Boris Cherny 分享使用体验：「我已经不再管理会话，想到什么就发送什么，Claude 会自行拆分为线程，而项目会记住我的工作方式。」该功能正在逐步向用户开放，未来几周内将全面铺开。

Google Labs 宣布推出新一代 CC（Care Companion）——面向家庭的 AI 代理，支持最多 5 位家庭成员，能同步共享日历与待办事项，自动生成「今日日程摘要」邮件，协助处理学校许可表格、购物清单等琐事，并能区分全局偏好与个人限制（如饮食禁忌、时区差异）。目前美国地区用户可加入等待名单或升级现有 CC。

Vercel CEO Guillermo Rauch 再次强调部署速度竞争：「明年将诞生的软件将超过计算机史总和」，Vercel 从 10 亿次部署到 24 亿次仅用 10 个月，现在已将部署全流程压缩至 1 秒以内——包括 CDN 分发、域名分配、安全观测和回滚能力。同时，当用户催促 Agent 快速提交热修复时，Agent 现在可以调用 `v0 –turbo –prod` 使用最快的构建机器。
