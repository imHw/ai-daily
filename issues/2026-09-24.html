Opus 5.5 正式上线成为 Claude 默认模型 · GPT-6 Sol 与 Luna 发布 API 价格砍半 · 形式化验证 16 PR 修复引爆代码质量讨论

Anthropic 正式发布 Claude Opus 5.5，并将其设为 Claude Code、Claude 应用和 Cowork 的默认模型。Cat Wu 表示 Opus 5.5 在 effort medium 下智能可比肩 Fable 5.1 但更快，rate limits 比 Opus 5 多走 25%。Boris Cherny 随即展示用 Opus 5.5 + Lean 对 Claude Agent SDK 做形式化验证，仅几条 prompt 就产出 16 个 PR 修复竞态条件等深层 bug，3324 赞引发「形式化验证是否是编码的未来」大讨论。Opus 5.5 还在 HAProxy C→Rust 移植中以 9.5 小时、成本降低 51% 击败 Fable 5.1 的 12 小时。

OpenAI 同日发布 GPT-6 Sol 和 Luna，API 价格永久下调 50%，Plus/Pro/Business 账户获 banked reset 额度。Thibault Sottiaux 称两款模型在写作和通用「一试就知道」质量上显著提升。Vercel CEO Guillermo Rauch 跑了 Next.js evals 四模型横评：Opus 5.5、GPT-6 Sol、Fable 5.1 均为 92%，Grok 4.7 为 87% 但便宜 2-7 倍。Box CEO Aaron Levie 从杰文斯悖论视角解读：成本每任务下降速度史无前例，每降一次成本就打开一批新 agent 用例——从全量数据扫描、安全审计到 agent swarm 工作流。

Opus 5.5 的 3D 建模能力也引发关注。Alex Albert 用 Opus 5.5 在 Blender 中从单条 prompt 重建了 1906 年旧金山 Market Street 的历史精确场景——从 Sanborn 地图、Miles Brothers 影片到 USGS 地形数据全链溯源，每栋建筑可回溯到数据源。Peter Steinberger 则发现 Astra 在 macOS 27 上找到 libuv 一个约 14 年的 bug，850 赞。
